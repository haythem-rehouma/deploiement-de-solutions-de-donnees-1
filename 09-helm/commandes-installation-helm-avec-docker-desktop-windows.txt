helm install une application dans K8s à partir d'un Helm Chart.
Par exemple,

helm install mon-nginx bitnami/nginx  ==> déploie Nginx dans le cluster Kubernetes.

APT = paquets Linux.
PIP = paquets Python.
HELM = applications Kubernetes.

apt => Ubuntu
yum => Redhat
npm => Node.js 
pip => Python
Helm => K8s
